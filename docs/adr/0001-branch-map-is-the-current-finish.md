# Текущий финиш — карта веток для будущей копии

11 октября 2026 финишем на сейчас названа полная карта веток @allai_robot: по ней потом собирается своя копия, исходный бот остаётся на сервере владельца. Канал по референсу этим финишем не является. Следующий бот входит в работу только отдельной строкой списка. Уже снятые блоки меню, команд, диалога, мастера агента и картинок заново не обходятся.

Рассматривались закрытое досье без цели собрать копию и повторный проход по экранам без своей копии. Оба варианта отклонены: нужна карта, которой хватает на копию.
