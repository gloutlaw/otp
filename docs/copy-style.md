# Образец текстов меню

Числа и даты в боте берутся из тарифа пользователя. Ниже — как это должно выглядеть.

Меню рисует остатки деревом. Экран «Лимиты» — буллетами и пояснением. Числа и название тарифа — жирным.

## Главное меню

```
🤖 **MewTon**
__Ваш личный AI-ассистент__

💎 **Ваш тариф: Старт**
продление включено

📊 **Обычные ответы**
├ Осталось: **400 из 400**
└ 🔄 Обновление через 6 дн. 23 ч. — 19.10 в 20:56 (UTC+3)

🧠 **Умные ответы**
├ Осталось: **20 из 20**
└ 📅 Действуют до 11.11.2026

ℹ️ Сначала расходуются запросы, включённые в тариф, затем — из дополнительных пакетов.

━━━━━━━━━━━━━━━━━━

✨ Выберите нужный раздел в меню ниже или просто отправьте свою задачу сообщением — MewTon поможет!
```

Строка про продление есть только у подписки. У бесплатного тарифа умные ответы помечены как пробные. Пакет, если он куплен, идёт таким же деревом.

## Лимиты

```
📊 **Ваши лимиты**

💎 Текущий тариф: **Старт**

💬 **Обычные ответы**
• Доступно: 400 из 400
• Обновление: 19.10 в 20:56 (UTC+3)

🧠 **Умные ответы**
• Доступно: 20 из 20
• Действуют до 11.11.2026

━━━━━━━━━━━━━━━━━━

📌 **Как работают лимиты?**

• Лимиты подписки рассчитываются в рамках 30-дневного периода и недель внутри него.
• Бесплатные сутки рассчитываются по времени UTC+3.
• Каждый умный ответ расходует один умный запрос.
• Сначала используются запросы, включённые в тариф, затем — запросы из дополнительных пакетов.
```
