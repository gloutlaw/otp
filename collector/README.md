# Сборщик ответов ботов

Скрипт обходит ботов из `bots.txt`, отправляет каждому `/start` и проходит меню на два уровня. Текст разделов и кнопки сохраняются деревом в `bots_functionality.txt`. Ссылки и Web App не открываются, кнопки с запросом телефона, геолокации или оплаты не нажимаются. Ключи читаются из `.env`, в коде их нет.

Запускайте на компьютере, с которого открывается Telegram. Для прогона лучше отдельный аккаунт: между ботами стоит пауза, но Telegram может временно ограничить аккаунт за автоматизацию.

## Подготовка

1. Зайдите на https://my.telegram.org под номером телефона аккаунта, с которого пойдёт сбор.
2. Откройте API development tools и создайте приложение.
3. Скопируйте `api_id` и `api_hash`.

Из этой папки:

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
```

В `.env` вставьте ключи без кавычек:

```
API_ID=1234567
API_HASH=your_api_hash_here
```

В `bots.txt` — юзернеймы, по одному на строку. Строки с `#` и пустые строки пропускаются. Символ `@` можно не писать.

```
@example_bot
another_bot
```

## Запуск

```bash
python collect_bots.py
```

При первом запуске скрипт предложит вход. Вариант 1 открывает QR-код: на телефоне, где аккаунт уже открыт, выберите Настройки → Устройства → Подключить устройство и отсканируйте его. Вариант 2 запрашивает цифровой код. Для этого номера SMS Telegram не отправляет. Если включена двухфакторная защита, следом спросит её пароль. Сессия сохранится рядом со скриптом, повторно код не спросит.

Файл `.env` и файл сессии в git не входят.
