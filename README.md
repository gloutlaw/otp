## Сборщик ответов ботов

Скрипт в [collector/](collector/). Он обходит ботов из `bots.txt`, отправляет `/start` и проходит меню на два уровня. Сейчас в списке `@allai_robot`. Ключи только в `collector/.env`.

Запускать локально, на компьютере, откуда открывается Telegram. Среда, из которой собирался этот проект, до серверов Telegram не достучалась. Как поставить ключи и запустить — в [collector/README.md](collector/README.md).

## Копия

Своя копия повторяет меню и диалог подопытного бота, а тарифы и лимиты берёт из собственной сетки. Решение: [ADR 0005 — собственная тарифная сетка](docs/adr/0005-own-tariff-grid.md), границы копии: [ADR 0002](docs/adr/0002-copy-follows-the-bot-not-the-offer.md).
